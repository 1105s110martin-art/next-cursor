# 《接下来｜》(暂定名) 策划案

> 基于用户提供的《女性主义叙事游戏策划方向稿(脱敏版)》，本文只做补充与技术落地，不删改原设定。

## 0. 开局确认结论
- 维度：2D
- 屏幕：纯竖屏手机形态（整个游戏就是一块竖屏手机，环境表现靠手机内容与背景氛围层承担）
- 核心玩法（用户确认）：在手机联系人列表上拖拽/长按整理关系；顺着默认路径几乎不用操作，偏离默认需要额外费力操作；过程中触发回忆；最终三结局。
- 技术栈：DOM（无刚体物理、无大量精灵、无粒子逐像素需求）+ Vite

## 一、概述（承原稿）
以女性人生选择为核心主题的叙事驱动游戏，聚焦"主体性"的辨认而非"正确选择"的灌输。玩家扮演即将步入婚姻的女主角，在筹备婚礼过程中整理手机联系人、回忆互动、重新审视选择，最终做出属于自己的决定。轻量交互 + 强叙事。鼠标/触屏皆可。

## 二、核心命题（承原稿）
真正的主体性，不是逃离某一种生活，也不是一定选择更自由更冒险的道路，而是在看清各种选择的幸福、代价与失去之后，仍然走向一条由自己决定并愿意承担的人生。游戏不预设"结婚=保守""独身=自由"。

## 三、故事与角色（承原稿 + 补充）
三阶段：老板娘（关系可重新协商）→ 海外朋友（选择必有代价）→ 妈妈（妥协不等于放弃主体性）。
女主角 28 岁、刚订婚；未婚夫体贴正常；妈妈是理解代价后妥协的前辈；老板娘离异独自经营小吃摊；海外朋友事业有成而孤独。

### 补充：每阶段的场次结构（统一模板，降低制作量）
每阶段 = 一屏"待办清单"(默认路径压力) + 一屏"联系人列表整理" + 1~2 段回忆 + 一次收束独白。
三阶段共用同一套界面语法，只换数据。

## 四、核心玩法机制（承原稿 + 具体化）

### 4.1 默认路径系统（阻力即压力）
- 每个阶段有一份"默认待办"（婚礼清单/亲友联络顺序/长辈安排），玩家什么都不做，底部会出现一个**"照着做"**按钮：单击即完成，进度前进，零成本。
- 偏离操作有明确的物理阻力，逐级递增：
  - 重排联系人：拖拽（需拖出 40px 以上才生效，松手会有回弹阻尼）
  - 修改标签：长按 700ms（进度环填满）
  - 移出列表：长按 1200ms 且需拖入底部"移除区"
- **阻力资源"这一天的力气"**：偏离操作消耗力气（1~3 点/次），每阶段初始 5~7 点。力气耗尽时仍可操作，但需连续二次确认长按（表现为"再确认一遍"）。力气不是失败条件，是身体感受。
- 顺路径推进不消耗力气；每次偏离成功，界面会有一个微小但可累积的变化（该联系人卡片的手写涂改痕迹保留到结局）。

### 4.2 联系人列表系统
初期：未婚夫、爸爸、妈妈、闺蜜、同事、老板娘、海外朋友，每人带预设关系标签（家人/好友/工作/未来家人）。
中期：可拖拽排序、改标签、隐藏；每次调整触发相应回忆。
后期：条目消失又出现、标签被涂改，最终只剩一个名字——她自己。

### 4.3 回忆触发机制
点击/长按/拖拽某联系人触发回忆：水彩静态插画 + 文字独白，30 秒内，可点击加速但不可跳过首段。回忆不给结论，只呈现处境。

### 4.4 高潮段落（替代眼动方案）
不使用摄像头/眼动硬件（风险过高）。替代实现：屏幕中央出现一行问题"那我呢？"，四周浮出干扰语句（"挺好的""该结了""大家都这样"）并逐渐增大音量与字号；玩家需**长按屏幕中央并保持 6 秒**，期间干扰字逐个淡出、环境音衰减，最后只剩心跳与一行光标。松手则干扰重新涌回。

### 4.5 结局分支判定
不做对话树。结局由三个隐性计数决定：
- 顺从计数（点击"照着做"次数）
- 偏离计数（成功的偏离操作次数）
- 关键三问（每阶段末一次单选，只两个选项：接受 / 说出来）
结局：偏离低且三问多为接受 → 「继续」；偏离中等或三问混合 → 「暂停」；偏离高且三问多为说出来 → 「离开」。三结局共用婚礼场景与 BGM，仅改人物位置、动作、对白与最后一镜。

## 五、交互（承原稿，删去硬件依赖）
点击、拖拽、长按、上下滑动切换手机内页（列表 / 待办 / 相册 / 日历）。手势追踪与眼动交互不实现，写在"未来扩展"。

## 六、视觉与音频（承原稿）
低饱和、温暖略疏离：米白、灰蓝、淡粉、旧木色。UI 模拟真实手机但字体略大、按钮圆润带手工感。回忆插画水彩晕染。婚礼场景以白为主但光影偏冷。
音频：城市环境音常在，音量随注意力变化；钢琴与弦乐、简单重复、关键处微变奏；高潮段落干扰声渐强，由交互压下。

## 七、结局设计（承原稿）
- 「继续」：如期举行婚礼，海边承认未来仍未知。定格并肩看海，字幕"这不是答案，这是开始。"
- 「暂停」：推迟婚礼。切回手机屏，列表只剩她自己，下方闪烁光标"接下来｜"。无文字说明。
- 「离开」：取消婚礼，独自搬入新公寓。行李箱里是老板娘的辣酱、海外朋友的明信片、妈妈没寄出的信。她笑了。淡出。

## 八、开发范围
本次实现完整三阶段 + 三结局（内容体量可控，共用界面语法），不做手势/眼动、不做新地图、不做骨骼动画、不做分支对话树。

## 九、教学方案（分级结论）
分级：**混合型**。手机界面点按滑动是常规认知，无需教；"默认路径 vs 偏离阻力"与"力气"是独创机制，需 just-in-time 教学。
- 第一阶段第一屏：待办清单上"照着做"按钮自带呼吸微光，玩家点了就走顺路径；同时列表首位联系人有一枚手写小箭头示意"也可以按住试试"。玩家首次长按成功后，屏幕边缘浮出一行手写体："偏离一次，要花掉一点力气。" 只出现一次。
- 力气图标（火柴造型）首次减少时，在其旁生长一行手写注解，2.5 秒后自行淡去。
- 帮助层：手机状态栏右侧一枚手写"?"翻页角标，点开是一页便签纸质感的操作说明（点/拖/长按/力气/滑动切页），按已解锁机制显示；玩家主动打开才出现，可随时开关。
- 无多页开场弹窗；教学只出现一次，进度存 localStorage。

## 十、内容工具方案
- **调参面板：有。** 参数：偏离拖拽生效阈值(px)、改标签长按时长(ms)、移除长按时长(ms)、每阶段初始力气、各偏离操作力气消耗、高潮段落长按时长(s)、回忆文字打字速度、环境音/干扰声/BGM 音量、结局判定阈值（偏离计数分界）。这些都是"拖一下立刻感受到"的手感数值，全部从 config 读取并支持热更。
- **内容编辑器：无。** 叙事文本与联系人数据是线性静态内容，没有空间坐标、玩家不会反复重排结构；条目数量固定在 3 阶段 × 7 联系人内，做编辑器属于为完整感造工具。文本直接以数据文件维护。

## 十一、视觉表现技术方案

**物质载体：一块被翻旧的手机 + 贴在它上面的手写便签/水彩纸。** 数字界面的冷静秩序 vs 手写涂改的人味，二者的冲突就是本作的主题在视觉上的形状。签名元素：铅笔涂改痕迹、火柴造型的"力气"、闪烁光标"接下来｜"。

### 角色
- 表现目标：不做立绘对视，人物只在回忆插画里以水彩剪影/侧身出现，面部含糊——记忆是主观且模糊的。避开"女性主义题材→苦大仇深大特写"的平均审美。
- 实现方案：生成素材，水彩静态插画，一图一场景；动效仅靠慢速位移与透明度呼吸，不做骨骼。
- 素材约定：统一平视中景、人物不直视镜头；透明底仅用于道具（辣酱瓶、明信片、信封），插画为满幅不透明。禁止镜像翻转人物、禁止把插画当精灵拆分。

### 相机
- 表现目标：镜头几乎不动——手机固定在屏幕中央，情绪靠内容层推移。高潮段落是唯一例外。
- 实现方案：CSS transform，手机整体极缓慢呼吸缩放(±0.4%)；高潮段落 scale 到 1.06 并让背景失焦（blur+暗角），松手回落。
- 素材约定：无。

### 背景/场景
- 表现目标：手机之外不是纯黑，是随阶段变化的一层"她此刻所在之处"的虚化环境（订婚宴桌面、小吃摊夜色、机场玻璃、老家客厅、婚礼白帐），大幅虚化只透气不抢戏。
- 实现方案：生成 5 张竖屏虚化环境图，作为手机背后的底层，切换用 3s 交叉淡入；上叠一层极淡纸纹与暗角。
- 素材约定：竖屏 832x1216，正面平视，画面中央留空（手机会盖住中央 60%），主体信息在四周；已在生成时做景深虚化，代码不再额外 blur 主图。禁止拉伸变形。

### UI 与弹窗
- 表现目标：像真手机，但每一处都被手改过——列表项是数字卡片，标签是手写贴纸，删除线是铅笔划的。禁止 SaaS 卡片栅格、毛玻璃、pill 徽章。
- 实现方案：DOM + CSS 实现界面骨架（状态栏、列表、按钮、便签帮助页）；纸纹、便签、火柴图标、贴纸标签用生成的透明底 PNG 贴图。弹窗即"贴在手机上的一张纸"，入场是纸片落下微旋，退场是被抽走。
- 素材约定：UI 贴图透明底、正面平铺无透视、无投影（投影由 CSS 给）；帮助便签 900x1200。

### 特效
- 表现目标：没有魔法感的特效。只有三种：铅笔涂改的划痕生长、长按进度环像墨水渗开、干扰文字如耳鸣般膨胀又散去。
- 实现方案：全部 CSS/SVG 代码绘制（stroke-dashoffset 画划痕、conic-gradient 做长按环、text-shadow + scale 做耳鸣），不生成特效素材。
- 素材约定：无。
